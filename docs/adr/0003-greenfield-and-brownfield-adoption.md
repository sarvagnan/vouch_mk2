# Provide distinct greenfield and brownfield adoption paths

The adoption module provides a greenfield fast lane that establishes governance before product
behavior and a brownfield path that bounds and characterizes pre-Vouch behavior before ratcheting
governed scope. Repository age is not the distinction: retained pre-governance behavior is
brownfield even in a new repository. A single universal onboarding flow was rejected because it
would either burden genuine greenfield work with legacy ceremony or let brownfield projects make
retroactive built-under-Vouch claims.
